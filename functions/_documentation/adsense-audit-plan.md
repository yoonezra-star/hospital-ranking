# 애드센스 콘텐츠 보강 기록

점검일: 2026-09-19

## 판단

Google이 개별 페이지별 거절 근거를 제공하지 않았으므로 아래는 코드와 공개 화면에서 확인한 개선 대상이다. 특정 결함이 유일한 거절 원인이라고 단정하지 않는다. 재심사 준비는 아직 완료되지 않았다.

- 로컬 병원 56개 모두 개별 원문 출처(sourceUrl)와 확인일(verifiedAt) 필드가 없다. 기본 목록은 전체 공공 API 검색 결과가 아니다.
- js/data.js에 샘플로 명시된 자료가 사용되었으며 출처 없는 평점과 후기 수가 노출됐다. 상세 화면은 후기 수가 없으면 전문의 수로 계산하는 코드까지 있었다.
- 기존 가이드 16개는 공식 근거로 연결되는 외부 링크가 없다. 본문이 공통 체크리스트에 집중되어 있다. 글자 수 자체를 Google의 승인 기준으로 해석해서는 안 된다.
- 상세 56개 URL은 같은 정적 HTML을 로딩한 뒤 JavaScript로 내용을 채운다. 동적 렌더링 자체가 정책 위반은 아니지만 현재 데이터 검증 부족과 결합해 별도 색인 대상으로 유지하기 어렵다.
- 기존 검색 커버리지 스크립트는 53개 중 41개에서 조건을 완화해 결과를 만든다. 원시 로컬 자료를 사용하는 테스트이므로 실제 화면의 정확 일치율은 아니며, 53/53이라는 출력만으로 검색 품질을 평가하면 안 된다.

## 이번 반영

1. 로컬 자료의 평점·후기 수를 비우고 목록, 지도 정보창, 상세, 지역 예시 카드에서 표시를 제거했다. 상세의 추정 함수와 AggregateRating도 제거했다.
2. 목록 정렬에서 평점과 후기 수를 제외했다. 조회 집계가 없는 '많이 보는 병원' 표현을 '병원 정보 살펴보기'로 수정했다.
3. 운영·광고·편집 안내를 실제 자료 제공 방식에 맞췄다. 전국 전체 목록과 실시간 접수 현황을 보장하지 않음을 안내한다.
4. guide-hospital-search.html을 추가했다. 검색 범위, 조건 완화 해석, 공식 조회 경로, 전화 질문, 저장하지 않는 체크리스트와 인쇄 기능을 제공한다. 본문은 JavaScript 없이도 읽을 수 있다.
5. 기존 가이드의 영문 파일명 형태 링크 문구를 해당 페이지의 한국어 제목으로 바꿨다. 가이드 목록과 메인에서 새 글로 연결했다.
6. 상세 페이지는 noindex,follow로 두고 사이트맵에서 제외했다. URL과 이용 경로는 유지한다. 기존 119개에서 새 가이드를 포함한 64개 URL로 변경했다. 확인 근거 없이 모든 페이지에 동일하게 붙였던 lastmod는 생략했다.
7. 콘텐츠 점검 및 브라우저 회귀 검증 스크립트를 추가했다.

noindex와 사이트맵 제외는 검색 색인 관리다. AdSense 심사에서 내용을 숨기거나 정책 적용을 피하는 수단이 아니며 콘텐츠 개선을 대신하지 않는다. 상세 정보가 검증되고 고유한 본문을 제공하면 색인 허용과 사이트맵 등록을 함께 복원한다.

## 다음 순서와 완료 기준

### 1. 병원 원자료 검증

- 현재 자료를 공식 병원 식별자와 대조해 병원명·주소·전화번호부터 확인한다. 이름만 같은 병원끼리 합치지 않는다.
- 각 필드에 원문 출처와 확인일을 저장한다. 확인되지 않은 전문의 수, 개원일, 장비, 주차, 요일별 진료 여부는 확정 사실로 표시하지 않는다.
- 확인 불가능한 샘플 레코드는 실제 병원 추천·신규 개원 영역에서 제외한다. 날짜나 숫자를 추정해 채우지 않는다.
- API 성공, 시간 초과, 빈 응답을 각각 검증한다. 비어 있으면 공식 조회 경로와 명확한 안내를 제공한다.
- 완료 기준: 공개하는 개별 사실을 공식 원문과 대조할 수 있으며 '정보 없음'과 '휴진/없음'을 구분한다.

### 2. 기존 가이드 16개 재편집

- 이용 빈도가 높은 주말 진료, 내시경, 치과 상담부터 근거 자료를 확보한다.
- 문장과 제목을 반복해 늘리지 않고 각 주제에 필요한 예약 절차, 문의 질문, 비교할 항목, 공식 확인 경로를 구성한다.
- 의료적 설명은 관련 공식 자료를 직접 인용·연결하고, 실제 감수를 받지 않았다면 전문가 감수라고 표시하지 않는다.
- 가이드의 작성일과 병원의 운영정보 확인일을 분리한다.
- 완료 기준: 각 문서가 다른 문서로 대체하기 어려운 질문을 해결하고 주요 설명의 근거를 찾을 수 있다.

### 3. 지역별 검색과 상세 화면

- 교하/운정 등 지역 검색 시 이름에 포함된 단어와 주소의 실제 생활권을 구분한다.
- 조건을 완화한 결과를 정확한 결과와 별도 표시하고 다른 지역 병원으로 조용히 대체하지 않는다.
- 검증한 병원부터 개별 내용과 메타데이터가 초기 HTML에 포함되도록 생성한다. 중복 랜딩은 실제 내용 검토 후 통합한다.
- 완료 기준: 검색어·지역·진료과·운영조건의 의미가 화면 결과와 일치하고 상세에서 출처를 확인할 수 있다.

### 4. 재검토 요청 전 확인

- GitHub 배포 결과와 실서비스에서 모바일 검색·상세·가이드·정정 링크를 확인한다.
- Search Console에서 대표 URL의 접근·색인 상태를 확인한다. 사이트맵 제출 성공과 AdSense 승인은 별개다.
- 미검증 정보, 비어 있는 결과, 중복 안내와 출처 없는 설명을 정리한 후 AdSense 검토를 요청한다.
- 고정 글 수, 글자 수, 대기 기간 또는 승인 보장 기준을 설정하지 않는다.

## 검증 명령

```powershell
node scripts/audit-content-value.js
node scripts/audit-search-coverage.js
node scripts/verify-content-quality.js
```

브라우저 검증은 Playwright와 Microsoft Edge가 필요하다. 기본 정적 서버를 사용하며 광고·지도 공급자의 외부 요청을 차단한다. 지도 인증과 라이브 API 동작 검증은 포함하지 않는다. 1280px/390px에서 체크리스트 변경·초기화·인쇄 호출, 병원명 검색, 상세 이동, 별점 구조화 데이터 제거 및 JS 비활성화 상태의 본문을 확인했다.

이 보고서는 공개 콘텐츠가 아니다. 루트 폴더 전체를 배포하는 현재 설정에서 정적 파일로 제공되지 않는 functions/_documentation에 보관한다. 기존 _redirects의 404 상태 규칙은 실제 요청을 차단하지 못했으며, noindex 헤더만으로 파일 접근을 막을 수는 없었다. 이전 공개 URL은 Pages가 지원하는 302 응답으로 /404 안내 화면에 연결한다. 이동한 문서 경로는 정적 자산에 포함되지 않으며 404 응답을 확인했다.
