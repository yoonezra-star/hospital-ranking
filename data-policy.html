병원 데이터 기준과 출처 안내

병원찾기는 병원 선택 전에 확인할 기본 정보를 모아 보여주는 참고 서비스입니다. 병원 정보는 변동될 수 있으므로, 페이지에 표시된 값만으로 운영 여부나 진료 가능 여부를 확정하지 않습니다.

2026년 9월 26일 기준: 검색·지역·진료과 안내에 사용하는 별도 스냅샷에는 건강보험심사평가원 병원기본정보 API에서 조회한 699개 기관이 들어 있습니다. 기존 로컬 보조자료 56건 중 17건은 공식 API 대조 이력이 있고, 39건은 미확인으로 명시해 자동 추천·대표 병원 영역에서 제외합니다.

정보 상태를 어떻게 구분하나요?

API 조회 완료암호화된 요양기호, 기관명, 주소 등 핵심 식별값이 건강보험심사평가원 응답과 연결된 상태입니다. 조회일과 출처를 함께 표시합니다.
추가 정보 조회상세·시설·장비·운영시간 API가 값을 반환한 경우에만 추가합니다. 값이 없으면 임의로 채우거나 주변 병원의 값으로 대체하지 않습니다.
확인 필요공식 식별값이 없거나 최신성을 확인하지 못한 로컬 자료입니다. 상세 페이지는 검색엔진 색인에서 제외하고 자동 추천·대표 목록에 사용하지 않습니다.

출처별로 무엇을 표시하나요?

서로 다른 기관의 데이터를 하나의 사실처럼 합치지 않습니다. 출처와 식별값이 맞는 경우에만 보완하며, 충돌하거나 비어 있는 항목은 확인 필요 상태로 남깁니다.

출처사이트에서 쓰는 항목한계와 확인 기준
건강보험심사평가원 병원정보서비스암호화된 요양기호, 기관명, 주소, 전화번호, 기관 종별, 개설일, 등록 진료과요양기관이 신고한 현황을 기반으로 하며 당일 접수 가능 여부나 치료 성과를 뜻하지 않습니다.
건강보험심사평가원 의료기관별 상세정보서비스조회 응답에 포함된 운영시간, 주차, 병상·시설, 의료장비상세 페이지에서 암호화된 요양기호로 추가 조회합니다. 응답이 없거나 출처끼리 시간이 다르면 확정값 대신 전화 확인 안내를 표시합니다.
국립중앙의료원 전국 병·의원 찾기 서비스기관명·주소가 일치하는 경우의 요일별 진료시간과 대표전화공개 운영정보이며 실시간 대기, 당일 의료진, 접수 종료, 검사 가능 여부를 보증하지 않습니다.
사이트 로컬 보조자료공식 API 장애 시 보여줄 수 있는 최소 기본정보공식 출처를 확인하지 못한 값은 확인 필요로 표시하고 색인·자동 추천 대상에서 제외합니다.

조회 결과가 다르거나 비어 있을 때

  1. 먼저 암호화된 요양기호를 기준으로 건강보험심사평가원 기본정보와 상세정보를 연결합니다.
  2. 다른 기관의 운영시간은 병원명과 주소가 같은 경우에만 후보 값으로 사용합니다.
  3. 두 출처의 시간이 다르거나 응답이 실패하면 어느 한쪽을 임의로 선택하지 않고 “전화 확인 필요”로 표시합니다.
  4. 토요일·야간·일요일 진료, 접수 마감, 임시 휴진, 당일 검사 가능 여부는 방문 날짜를 말하고 병원에 직접 확인하도록 안내합니다.
중요: “API 조회 완료”는 기관 정보의 출처가 확인됐다는 뜻이며, 의료 품질 인증이나 추천 등급이 아닙니다.

공식 확인 경로

  • 건강보험심사평가원 건강지도에서 기관명, 주소, 진료과를 대조할 수 있습니다.
  • 공공데이터포털의 병원정보서비스 명세에서 제공기관, 갱신 정보, 이용 조건을 확인할 수 있습니다.
  • 전국 병·의원 찾기 서비스 명세에서 진료요일·기관명 등 조회 항목을 확인할 수 있습니다.
  • 응급 증상이나 급격한 상태 악화는 사이트 검색보다 119, 응급실, 의료진 안내가 우선입니다.

정정 요청 방법

병원명, 주소, 전화번호, 진료과, 운영시간 또는 링크가 실제와 다르면 문의 페이지 또는 replyleaders@naver.com으로 알려 주세요. 병원명과 페이지 주소, 수정 항목, 공식 홈페이지나 공공기관 등 확인 가능한 근거를 함께 보내주시면 검토가 빠릅니다.

  • 근거가 확인된 정보부터 순차적으로 수정합니다.
  • 수정 전까지는 기존 값과 함께 방문 전 확인 안내를 유지합니다.
  • 제보만으로 의료기관의 진료 품질이나 만족도를 평가하지 않습니다.
  • 병원 폐업·이전·전화번호 변경처럼 이용에 직접 영향을 주는 항목을 우선 검토합니다.

표시하지 않는 정보

수집 근거가 없는 평점, 후기 수, 치료 성공률, 환자 만족도 순위는 표시하거나 추정하지 않습니다. 병원 목록의 정렬은 검색 조건과 정보 충실도를 기준으로 한 탐색 보조일 뿐, 의료 수준이나 치료 결과의 순위가 아닙니다.
